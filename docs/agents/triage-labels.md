# 分诊标签（Triage Labels）

各技能以五个标准分诊角色来表达。本文件将这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                         |
| -------------------------- | ------------------ | ---------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估该议题         |
| `needs-info`               | `needs-info`       | 等待报告者补充更多信息       |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可交给 AFK 智能体  |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                 |
| `wontfix`                  | `wontfix`          | 不予处理                     |

当技能提到某个角色（例如"应用 AFK 就绪的分诊标签"）时，使用上表中对应的标签字符串。

修改右列即可匹配你实际使用的词汇表。
